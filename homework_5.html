Exercise 1

Riemann and Lebesgue integration

Riemann and Lebesgue integration use different approaches to calculate an integral. Riemann integration divides the domain into smaller intervals and approximates the area using rectangles. Lebesgue integration, instead, divides the range of the function into value levels and measures the parts of the domain corresponding to each level. In this exercise, we apply both methods to different functions and compare their results with the exact integral. By increasing the number of subdivisions, we can observe how the numerical error changes and which method gives a more accurate approximation. We also consider functions that behave differently under the two definitions of integration.

Select a function and adjust the number of domain partitions (Riemann) and value levels (Lebesgue). The calculator approximates the integral using both methods and compares the results, showing the numerical errors and how they decrease as the number of subdivisions increases. Among the available functions, there are two interesting cases:

Rational / Irrational (Dirichlet Function)

This function equals 1 when x is rational and 0 when x is irrational. It is discontinuous at every point, so it is not Riemann integrable. However, its Lebesgue integral is 0 because rational numbers have measure zero.

Popcorn (Thomae's Function)

This function equals 1/q when x is a rational number written as p/q in lowest terms, and 0 when x is irrational. Rational numbers with smaller denominators produce taller spikes, giving the function its popcorn-like appearance. Unlike the Dirichlet function, it is integrable under both Riemann and Lebesgue, with an integral equal to 0.

Note: These functions are difficult to approximate numerically because computers only evaluate a finite number of points. The numerical results may therefore differ from their theoretical behavior.

How does the Riemann algorithm work?

Rₙ = ∑ᵢ f(a + (i+½)Δx) Δx

The midpoint rule is applied over N equal intervals. It is a Riemann sum, often with O(N⁻²) error for smooth functions. Discontinuities and singularities change this behavior.

How does the Lebesgue algorithm work?

Lₘ = Δt ∑ⱼ μ({x : f(x) ≥ tⱼ})

The value axis is discretized, and the exact measures of the superlevel-set preimages are evaluated for these specific functions. The midpoint rule is then used over the levels. For 1/√x, the value integral is truncated at a finite threshold.

Important qualifications.

The Lebesgue method used in this project is designed for the selected functions and may not work directly with other functions.

Some functions also require special attention:

  • 1/√x: Its integral equals 2, but the function becomes infinitely large near x = 0, so standard Riemann integration cannot be applied directly.
  • Dirichlet function: It can be integrated using Lebesgue integration, but not Riemann integration.
  • Thomae function (Popcorn): Both methods can integrate it, giving a result of 0.

For these particular functions, numerical approximations may not fully reflect their mathematical behavior. Therefore, the theoretical results are important when interpreting the calculations.

Exercise 2

Standard normal cumulative distribution function (CDF)

In this exercise, we calculate the cumulative distribution function (CDF) of the standard normal distribution, which gives the probability that a normally distributed variable takes a value less than or equal to a given number z. This probability corresponds to the area under the bell-shaped curve to the left of z. Since this area cannot be calculated using elementary functions, we use three numerical methods: Simpson's rule, which approximates the area using small intervals; the erf power series, which calculates the probability through a mathematical series; and an approximation of the error function (erf), which provides a fast estimate. We then compare the results of these methods to see how accurate and efficient they are.

Mathematical Definition of the CDF

The standard normal CDF is calculated by integrating the probability density function from negative infinity up to a given value z. This integral represents the probability that a standard normal random variable is less than or equal to z.

Φ(z) = (1/√(2π)) ∫₋∞ᶻ e^(−t²/2) dt

However, this integral cannot be expressed using elementary functions. Instead, it can be written exactly using the error function (erf):

Φ(z) = ½[1 + erf(z/√2)]

Here, z is the value at which we want to calculate the cumulative probability, while erf is a special mathematical function related to the integral of the Gaussian curve. Although this formula is exact, numerical algorithms are still needed to evaluate it on a computer.

① Composite Simpson rule

Φ(z) = ½ + ∫₀ᶻ φ(t) dt

Simpson's rule is a numerical method used to approximate the area under a curve. Instead of calculating the integral directly, it divides the interval into smaller parts and uses parabolas to estimate the area. For the normal CDF, we use: Φ(z) = ½ + ∫₀ᶻ φ(t) dt The value ½ represents the probability to the left of zero, while the integral calculates the additional area between 0 and z (or subtracts it when z is negative). Increasing the number of subdivisions (N) generally makes the result more accurate, but also requires more calculations.

② Power series

erf(u) = (2/√π) Σₖ (−1)ᵏ u²ᵏ⁺¹ / [k!(2k+1)]

This method calculates the normal CDF using the error function, called erf. Instead of dividing the area into intervals, it approximates erf by adding a sequence of mathematical terms: erf(u) = (2/√π) Σₖ (−1)ᵏ u²ᵏ⁺¹ / [k!(2k+1)] Each additional term can improve the approximation. The method works well for values close to zero, but can become numerically inaccurate for large values of |z|. In our calculator, when |z| is greater than 5, we use an alternative integration method to avoid this problem.

③ erf approximation

erf(u) ≈ sgn(u)·[1 − P(t)e^(−u²)]

This method also uses the error function, but instead of calculating a long series, it uses a predefined mathematical formula that gives a good approximation with only a few calculations. erf(u) ≈ sgn(u) · [1 − P(t)e^(−u²)] Here, P(t) is a polynomial designed to approximate the error function accurately. Unlike Simpson's rule or the power series, this method does not require increasing the number of intervals or terms. It is therefore very fast, although its result may be slightly less accurate than the other methods when they are calculated with sufficient precision.

Why Can't the Normal CDF Be Calculated Using Elementary Functions?

The standard normal CDF is defined using an integral involving the function e-x²/2. Unlike many other integrals, this one cannot be solved using only elementary functions, such as polynomials, exponentials, logarithms or trigonometric functions. This result is explained by Liouville's theorem, which provides mathematical conditions for determining whether an integral can be expressed using elementary functions. In the case of the normal distribution, these conditions cannot be satisfied. Therefore, we cannot find an elementary formula for its integral. However, this does not mean that the CDF cannot be calculated. We can use numerical methods or special mathematical functions instead.

The Error Function (erf)

To represent the normal CDF exactly, mathematicians introduce a special function called the error function (erf). The relationship between the two functions is:

Φ(z) = ½ [1 + erf(z/√2)]

This formula provides an exact mathematical expression for the normal CDF. However, since erf is itself defined through an integral, computers still need numerical algorithms to calculate its values. This is why methods such as Simpson's rule, power series and erf approximations are useful.

Accuracy and Numerical Limitations

To evaluate the accuracy of our algorithms, we compare their results with known reference values of the standard normal CDF. Some of these reference values can be checked using tables published by the National Institute of Standards and Technology (NIST). The methods generally produce accurate results, but their precision depends on the value of z and the algorithm used. For example, when z is far from zero, some calculations can lose precision because they involve extremely small probabilities or subtraction between numbers that are almost equal. In our calculator, we handle these situations by using alternative calculations for large values of z. In particular:

  • For |z| > 4: Simpson's method calculates the small remaining probability directly to avoid losing numerical precision.
  • For |z| > 5: The power series is replaced with a more stable numerical integration method.

These adjustments help maintain accurate results across the interval considered in this project.

Final Discussion

Results and Conclusions

Riemann and Lebesgue Integration

In the first exercise, we compared Riemann and Lebesgue integration by applying both numerical approaches to different functions. By analyzing the results, errors and convergence tables, we can make the following observations:

  • Both approaches converge to the same result for Riemann-integrable functions. When a bounded function is Riemann integrable, its Lebesgue integral has the same value. As we increase the number of subdivisions, both numerical approximations generally get closer to the exact integral. This can be observed in functions such as x² and sin(x).
  • The two methods can converge at different speeds. Increasing the number of domain partitions (N) or value levels (M) usually reduces the numerical error. However, the speed of convergence depends on the properties of the function and on the approximation method. For example, a smooth function may be approximated very accurately using Riemann's midpoint rule, while the Lebesgue-based method may require more levels to obtain similar accuracy.
  • The Dirichlet function is not Riemann integrable. This function equals 1 for rational numbers and 0 for irrational numbers. Since both types of numbers are present in every interval, Riemann sums can give different results depending on the points selected. However, the set of rational numbers has measure zero, so its Lebesgue integral is 0. This example shows an important difference between the two definitions of integration.
  • The Thomae (Popcorn) function is integrable using both methods. Although the function is discontinuous at every rational number, its values become smaller for rational numbers with larger denominators. The function is continuous at every irrational number and is Riemann integrable. Both the Riemann and Lebesgue integrals equal 0. This shows that a function can have infinitely many discontinuities and still be integrable using both approaches.
  • The function 1/√x requires special treatment. As x approaches 0, the function grows without bound. Therefore, it is not Riemann integrable in the ordinary sense for bounded functions. However, its improper Riemann integral and Lebesgue integral both equal 2. In the numerical Lebesgue approximation, we must limit the maximum value considered, introducing an additional approximation error. Increasing this limit helps reduce that error.

Overall, the experiments show that both approaches produce the same integral when the function is Riemann integrable, even though their numerical convergence and computational costs may differ. Lebesgue integration is also applicable to certain functions that cannot be integrated using the traditional Riemann definition.

Normal CDF Calculation

In the second exercise, we implemented and compared three numerical methods for calculating the cumulative distribution function of the standard normal distribution. We evaluated their accuracy, convergence and computational efficiency.

  • Simpson's rule provides accurate results and converges quickly. This method divides the integration interval into smaller parts and approximates the area under the normal density curve using parabolas. Increasing the number of subdivisions (N) generally reduces the error. For sufficiently smooth functions, Simpson's rule has an error that decreases approximately proportionally to 1/N⁴. However, using more subdivisions also requires more evaluations of the function, increasing the computational cost.
  • The erf power series is effective for values close to zero. This method calculates the normal CDF by approximating the error function (erf) through a sequence of mathematical terms. Adding more terms generally improves the accuracy of the result. Near zero, the series converges efficiently and can provide very precise values. However, for large absolute values of z, numerical cancellation may reduce accuracy. For this reason, our calculator uses an alternative method when |z| exceeds 5.
  • The erf approximation is very fast, but has limited precision. Instead of computing an integral or summing a large number of terms, this method uses a predefined mathematical approximation of the error function. It requires only a small, fixed number of calculations, making it computationally efficient. Although it provides accurate estimates for many practical applications, it generally cannot reach the same precision as a sufficiently refined Simpson calculation or a stable high-precision series evaluation.
  • Numerical stability is particularly important for very small probabilities. When z is far from zero, the normal CDF approaches either 0 or 1. In these situations, some formulas may lose precision because they subtract numbers that are almost equal. Scientific libraries address this problem using specialized algorithms that calculate very small probabilities more reliably. Our implementation also uses alternative calculations for values far from zero to improve numerical stability.

Overall, all three methods can be used to approximate the normal CDF, but each has different advantages. Simpson's rule offers high accuracy when enough subdivisions are used, the power series works particularly well near zero, and the erf approximation provides fast results with a small numerical error. The most suitable method depends on the required accuracy, the value of z and the available computational resources.
